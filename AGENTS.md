# Agent notes

This project uses Impeccable as the primary design skill. Complementary anti-slop skills live in `.cursor/skills/`.

## Always

- Read `PRODUCT.md` before any UI work.
- For new surfaces, follow `.cursor/skills/impeccable/SKILL.md` and `reference/new-work.md`. Run `concept-seed` before inventing a visual world.
- After UI exists, keep `DESIGN.md` in sync with `/impeccable document`.
- Placeholders for work, education, and skills are intentional. Do not invent employers, schools, metrics, or clients.

## Skills

| Skill | Use |
|---|---|
| `impeccable` | Design vocabulary, detector, live, overdrive |
| `frontend-design` | Distinctive direction, anti-template |
| `emil-design-eng` | Easing, duration, interaction polish |
| `animate` / `review-animations` | Motion craft and audit |

The paste-ready build prompt is in `PORTFOLIO-DESIGN-PROMPT.md`.
